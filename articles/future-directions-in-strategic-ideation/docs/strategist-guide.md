# Strategist Guide

This scaffold supports future-ready strategic ideation analysis through ten recurring questions:

1. Is the problem frame strong enough for future uncertainty?
2. Does the evidence support the level of confidence?
3. How does the idea perform across plausible scenarios?
4. What options does the idea preserve or close?
5. Which stakeholders shape the idea, and who bears burden?
6. How is AI used, disclosed, verified, and governed?
7. How does the idea affect systems, sustainability, and long-term responsibility?
8. What experiments or tests should happen before commitment?
9. How will decision memory preserve rationale, dissent, and outcomes?
10. What stop rules and revision triggers will support adaptive learning?

Recommended workflow:

- Run `python3 python/future_ideation_diagnostics.py`
- Review `outputs/tables/future_ready_idea_scores.csv`
- Review `outputs/tables/scenario_option_scores.csv`
- Review `outputs/tables/ai_governance_scores.csv`
- Review `outputs/tables/collective_intelligence_scores.csv`
- Review `outputs/tables/learning_memory_scores.csv`
- Use the generated markdown report for workshop discussion.
