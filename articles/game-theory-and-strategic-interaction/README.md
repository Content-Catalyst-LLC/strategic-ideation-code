# Game Theory and Strategic Interaction

This article folder contains an advanced, strategist-facing companion scaffold for **"Game Theory and Strategic Interaction."**

The repository treats game theory as a practical strategy capability: a disciplined way to map actors, incentives, payoffs, information asymmetries, timing, equilibrium logic, cooperation fragility, signals, credibility, repeated interaction, mechanism design, behavioral realism, ethics, power, and strategic learning memory.

## Why this exists

Strategic decisions rarely happen in isolation. Competitors respond. Partners negotiate. Regulators intervene. Users adapt. Stakeholders cooperate, defect, delay, imitate, retaliate, or form coalitions. This scaffold helps teams avoid naive strategy by testing whether ideas survive strategic response.

## Advanced strategist-facing capabilities

- Game-theoretic strategy diagnostics
- Actor and player mapping
- Payoff and incentive analysis
- Strategy-set comparison
- Information asymmetry review
- Timing and sequencing analysis
- Equilibrium diagnosis
- Cooperation-fragility scoring
- Repeated-interaction and reputation analysis
- Signaling and credibility review
- Mechanism-design and rule-redesign analysis
- Behavioral game-theory adjustment
- Ethics and power review
- Strategic interaction learning-memory records
- SQL schemas for actors, incentives, payoffs, signals, mechanisms, cooperation risks, ethics, governance, and learning memory
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible strategic interaction analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/game_theory_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_game_theory_analytics.py
```
