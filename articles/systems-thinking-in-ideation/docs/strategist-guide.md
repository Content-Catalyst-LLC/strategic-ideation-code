# Strategist Guide

This scaffold is designed for professional systems-based ideation work. It supports ten recurring questions:

1. **Pattern:** What keeps happening?
2. **Boundary:** What system are we actually analyzing?
3. **Structure:** What feedback, incentives, delays, stocks, rules, and information flows produce the pattern?
4. **Leverage:** Where could intervention change behavior most deeply?
5. **Stakeholders:** Whose experience, burden, or risk is missing from the model?
6. **Consequences:** What else might the intervention set in motion?
7. **Portfolio:** Are ideas distributed across leverage levels?
8. **Evidence:** How can structural assumptions be tested?
9. **Learning:** How will implementation evidence update the model?
10. **Memory:** What should be preserved for future strategy?

## Recommended workflow

### Step 1: Score systems-ideation capacity

Use `systems_profiles.csv` and the Python diagnostic to assess feedback awareness, leverage sensitivity, root-cause depth, stakeholder visibility, boundary quality, stock-flow awareness, delay awareness, learning capacity, and risk.

### Step 2: Review feedback loops

Use `feedback_loops.csv` to identify reinforcing loops, balancing loops, delay risks, and burden risks.

### Step 3: Rank leverage points

Use `leverage_points.csv` to compare intervention depth, feasibility, evidence, legitimacy, reversibility, sensitivity, risk, and time to effect.

### Step 4: Audit boundaries

Use `boundary_reviews.csv` to test whether the system boundary includes stakeholders, downstream effects, externalities, implementation realities, ecological or social context, and hidden dependencies.

### Step 5: Review unintended consequences

Use `unintended_consequences.csv` to identify burden transfer, metric gaming, delayed fragility, adaptive resistance, and other system responses.

### Step 6: Manage the intervention portfolio

Use `intervention_portfolio.csv` to balance surface fixes, information-flow interventions, rules, goals, mental-model shifts, and learning infrastructure.

### Step 7: Build learning loops

Use `learning_loops.csv` to ensure feedback, revision triggers, decision memory, implementation signals, and governance response are built into strategy.
