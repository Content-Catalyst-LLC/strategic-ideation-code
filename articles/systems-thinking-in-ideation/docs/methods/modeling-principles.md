# Modeling Principles for Systems Thinking in Ideation

## 1. Start with patterns, not events

A single event may be visible, but systems thinking asks what recurring pattern is being produced.

## 2. Treat structure as the cause of behavior

Strategic ideas should target feedback, incentives, rules, information flows, boundaries, stocks, delays, and mental models.

## 3. Separate system maps from reality

Models are representations. They clarify and distort. Treat them as hypotheses that should be tested and revised.

## 4. Search for leverage points

Do not stop at parameter changes or surface fixes. Compare deeper interventions in feedback, information, rules, goals, and paradigms.

## 5. Review boundaries deliberately

System boundaries determine which causes, stakeholders, and consequences are visible.

## 6. Anticipate unintended consequences

Every intervention can create feedback, burden transfer, gaming, delayed fragility, or adaptive resistance.

## 7. Build learning loops

Implementation evidence should update assumptions, models, interventions, and commitments.

## 8. Preserve decision memory

Record the pattern, boundary, structural drivers, leverage points, evidence pathway, revision triggers, and archived learning.
