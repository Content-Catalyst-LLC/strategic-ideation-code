# Systems Thinking in Ideation

This article folder contains an advanced, strategist-facing companion scaffold for **"Systems Thinking in Ideation."**

The repository treats systems thinking as a disciplined approach to idea generation that moves from symptoms to recurring patterns, from patterns to structure, from structure to leverage points, and from leverage points to adaptive strategic interventions.

## Why this exists

Strategic ideas do not enter neutral environments. They enter systems of feedback, incentives, delays, constraints, authority, information, trust, capacity, and adaptation. This scaffold helps strategists generate ideas that target system structure rather than only visible symptoms. It supports systems-profile diagnostics, feedback-loop review, leverage-point scoring, boundary analysis, unintended-consequence review, intervention portfolio design, learning-loop governance, and decision memory.

## Advanced strategist-facing capabilities

- Systems-ideation profile scoring
- Feedback-loop and structural-driver diagnostics
- Leverage-point ranking across parameters, buffers, information flows, rules, goals, and mental models
- Boundary quality and stakeholder visibility review
- Stock-flow and accumulation analysis
- Time-delay and delayed-consequence review
- Unintended-consequence and second-order-effect audits
- Structural intervention portfolio scoring
- Learning-loop and decision-memory design
- SQL schemas for systems, components, relationships, feedback loops, stocks, flows, delays, leverage points, interventions, evidence, stakeholders, implementation records, and learning loops
- Optional advanced analytics with pandas and matplotlib
- Multi-language examples for reproducible systems-ideation analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/systems_ideation_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_systems_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
