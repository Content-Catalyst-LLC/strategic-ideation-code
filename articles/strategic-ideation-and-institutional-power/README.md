# Strategic Ideation and Institutional Power

This article folder contains an advanced, strategist-facing companion scaffold for **Strategic Ideation and Institutional Power**.

The repository treats institutional power as a structural condition of strategic ideation: agenda-setting, authority, sponsorship, feasibility, evidence, participation, dissent, classification, resources, incentives, institutional memory, AI mediation, and governance all shape which ideas enter strategy and which disappear before formal evaluation.

## Advanced strategist-facing capabilities

- Institutional power diagnostics for strategic ideas
- Agenda-setting and attention-boundary review
- Feasibility, realism, and constraint analysis
- Sponsorship, gatekeeper, and authority mapping
- Evidence parity and credibility review
- Participation influence and tokenism diagnostics
- Dissent protection and counteridea review
- Classification power and taxonomy review
- Resource allocation and incentive analysis
- Institutional memory and forgetting audit
- AI-assisted ideation power review
- Power-aware governance design
- SQL schema for ideas, sponsors, gatekeepers, stakeholders, evidence, dissent, resources, narratives, memory records, AI use, and governance review
- Python, R, Julia, SQL, Rust, Go, C++, Fortran, and C examples

## Quick start

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/institutional_power_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_institutional_power_graph.py
```
