# First Principles Thinking in Strategy

This article folder contains an advanced, strategist-facing companion scaffold for **First Principles Thinking in Strategy**.

The scaffold treats first principles thinking as a disciplined method for separating inherited assumptions from real constraints, decomposing strategic systems, identifying governing mechanisms, reconstructing options from fundamentals, and testing rebuilt strategies against reality.

## Advanced strategist-facing capabilities

- Assumption-load scoring and assumption-burden registers
- Real-versus-assumed constraint classification
- Strategic system decomposition
- Governing mechanism mapping
- Reconstructed option scoring
- Reality-test and prototype planning
- Institutional lock-in and inherited-category review
- Ethical legitimacy and stakeholder-burden review
- Decision-memory templates for reconstructed strategies
- SQL schemas for first principles analysis systems
- Optional advanced analytics with pandas and matplotlib
- Multi-language examples for reproducible strategic analysis

## Quick start

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/first_principles_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_first_principles_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
