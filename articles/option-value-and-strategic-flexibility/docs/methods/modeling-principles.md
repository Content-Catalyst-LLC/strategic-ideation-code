# Modeling Principles for Option Value and Strategic Flexibility

1. Flexibility is valuable when uncertainty is material and later information improves commitment quality.
2. Reversibility changes the evidence burden.
3. Learning must be decision-relevant.
4. Flexibility needs governance, evidence thresholds, and decision rights.
5. Modularity creates real flexibility.
6. Options expire when windows close, stakeholder patience erodes, or information decays.
7. Exit is a strategic capability.
8. Flexibility has cost.
9. Flexibility has ethics because one actor's option can become another actor's uncertainty.
10. Decision memory preserves why a commitment was staged or delayed.
