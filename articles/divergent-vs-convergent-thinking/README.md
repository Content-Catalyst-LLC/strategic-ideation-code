# Divergent vs Convergent Thinking

This article folder contains an advanced, strategist-facing companion scaffold for **"Divergent vs Convergent Thinking."**

The repository treats divergence and convergence as a disciplined strategic search system: expanding the option space, applying criteria and constraints, testing ideas against evidence, preserving decision memory, and balancing exploration with exploitation.

## Why this exists

Organizations often fail strategically because they converge too early, diverge without discipline, evaluate ideas through biased criteria, or lose learning across iterations. This scaffold helps strategists diagnose how well a team or institution moves between possibility and commitment.

## Advanced strategist-facing capabilities

- Divergence–convergence process profiling
- Premature convergence risk scoring
- Unbounded divergence risk scoring
- Exploration–exploitation balance analysis
- Constraint classification and selection-readiness review
- Evaluation criteria and selection-integrity diagnostics
- Stakeholder inclusion and legitimacy gap review
- Iteration quality and evidence-contact diagnostics
- Idea portfolio and decision-memory templates
- SQL schemas for idea sets, criteria, constraints, evaluation rounds, prototypes, and decisions
- Optional advanced analytics with pandas and matplotlib
- Multi-language examples for reproducible strategy analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/divergence_convergence_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_divergence_convergence_analytics.py
```
