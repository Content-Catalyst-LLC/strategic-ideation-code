# Lateral Thinking in Strategy

This article folder contains an advanced, strategist-facing companion scaffold for **"Lateral Thinking in Strategy."**

The repository treats lateral thinking as disciplined frame disruption: identifying the dominant frame, surfacing hidden assumptions, applying provocation, reversal, random entry, escape, forced association, and concept extraction, then reconstructing lateral insights into testable strategic options.

## Why this exists

Organizations often confuse lateral thinking with loose brainstorming or novelty for its own sake. In strategy, lateral thinking is only valuable when frame disruption leads to better problem representations, stronger options, useful hypotheses, stakeholder legitimacy, systems alignment, and implementation learning.

This scaffold helps strategists diagnose frame rigidity, evaluate lateral moves, compare reframed problem statements, detect drift risk, and integrate discontinuous ideas with convergence discipline.

## Advanced strategist-facing capabilities

- Frame-rigidity and lateral-capacity diagnostics
- Dominant-frame inventory and assumption disruption
- Provocation, reversal, escape, random-entry, forced-association, and concept-extraction logs
- Lateral-move scoring and drift-risk analysis
- Reframed problem statement quality review
- Convergence-integration and prototype-readiness diagnostics
- Stakeholder legitimacy and political-safety review
- Systems-fit and second-order-effect checks
- Decision-memory templates for rejected, deferred, and advanced reframes
- SQL schemas for frames, assumptions, lateral moves, reframes, prototypes, stakeholder review, and decisions
- Optional advanced analytics with pandas and matplotlib
- Multi-language examples for reproducible lateral-thinking analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/lateral_thinking_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_lateral_analytics.py
```

They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
