# Strategist Guide

This scaffold supports strategic effectiveness measurement through ten recurring questions:

1. What was the strategy meant to accomplish?
2. Which indicators reflect performance, alignment, resilience, adaptability, impact, learning, and ethics?
3. Which indicators are leading and which are lagging?
4. What is the quality of the evidence?
5. What are the main attribution and causality challenges?
6. What important outcomes are not visible in the dashboard?
7. What stakeholder evidence should be included?
8. What metric distortions or gaming risks exist?
9. What evidence should trigger revision, scaling, pausing, or stopping?
10. How will decision memory preserve what was learned?

Recommended workflow:

- Run `python3 python/strategic_effectiveness_diagnostics.py`
- Review `outputs/tables/strategic_effectiveness_scores.csv`
- Review `outputs/tables/indicator_quality_scores.csv`
- Review `outputs/tables/evidence_confidence_scores.csv`
- Review `outputs/tables/feedback_learning_scores.csv`
- Review `outputs/tables/ethics_power_scores.csv`
- Use the generated markdown report for workshop discussion.
