# Institutional Memory and Idea Systems Workshop

## Purpose

Help a team determine whether strategic ideas are preserved as reusable intelligence or scattered across inaccessible records.

## Suggested duration

3 to 4 hours.

## Outputs

- memory inventory
- idea lifecycle map
- metadata quality report
- decision-memory assessment
- learning-loop integration review
- retrieval test report
- reuse and transfer guide
- stewardship model
- continuity plan
- ethics and power review
