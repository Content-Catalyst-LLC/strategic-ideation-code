# Modeling Principles for Institutional Memory and Idea Systems

1. Institutional memory is not storage; it is usable strategic meaning preserved over time.
2. Idea systems should manage the full lifecycle from signal to concept, hypothesis, option, prototype, decision, implementation, learning, reuse, and retirement.
3. Decision memory should preserve rationale, evidence, assumptions, alternatives, tradeoffs, dissent, owners, and revision triggers.
4. Learning loops should update idea records, confidence levels, assumptions, and reuse conditions.
5. Retrieval should answer strategic questions, not only find documents.
6. Reuse requires portable knowledge plus contextual transfer cautions.
7. Tacit knowledge should be preserved through retrospectives, narrative records, and handoffs, not only templates.
8. Stewardship prevents repositories from decaying into untrusted archives.
9. Continuity planning protects memory through turnover, leadership transition, project closure, and tool migration.
10. Ethical memory preserves voice, burden, dissent, failure, uncertainty, redress, and accountability while respecting privacy and retention limits.
