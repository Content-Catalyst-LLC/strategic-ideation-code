# Strategist Guide

This scaffold supports institutional memory and idea-system analysis through ten recurring questions:

1. Where do strategic ideas, evidence, assumptions, decisions, and lessons currently live?
2. How do ideas move through lifecycle stages?
3. Does each idea preserve source, context, evidence, assumptions, owner, status, and review date?
4. Can future teams understand why decisions were made?
5. Do prototypes, pilots, implementation reviews, and stakeholder feedback update idea records?
6. Can users retrieve relevant memory when decisions arise?
7. Can old ideas and lessons be reused responsibly with context and transfer cautions?
8. Who maintains taxonomies, metadata, status, record freshness, and decision memory?
9. Can memory survive turnover, leadership change, project closure, and platform migration?
10. Whose ideas, evidence, burden, dissent, and failures are preserved?

Recommended workflow:

- Run `python3 python/institutional_memory_diagnostics.py`
- Review `outputs/tables/memory_system_scores.csv`
- Review `outputs/tables/idea_lifecycle_scores.csv`
- Review `outputs/tables/decision_memory_scores.csv`
- Review `outputs/tables/retrieval_reuse_scores.csv`
- Review `outputs/tables/learning_update_scores.csv`
- Review `outputs/tables/stewardship_ethics_scores.csv`
- Use the generated markdown report for workshop discussion.
