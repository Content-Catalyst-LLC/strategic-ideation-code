# Empathy and User-Centered Ideation

This article folder contains an advanced, strategist-facing companion scaffold for **"Empathy and User-Centered Ideation."**

The repository treats empathy as disciplined strategic inquiry rather than sentiment or workshop theater. It helps strategists examine lived experience, stakeholder context, projection risk, hidden burden, journey friction, unmet need, observation evidence, reframing quality, multi-stakeholder impact, ethical legitimacy, systems effects, prototype learning, decision linkage, and institutional memory.

## Why this exists

Organizations often generate ideas from internal assumptions, executive priorities, metrics, roadmaps, or technical possibility. Those ideas may be internally coherent yet fail in use because they misunderstand lived experience. This scaffold helps teams turn empathy into practical strategic evidence: what people experience, what they do, what they avoid, where they absorb burden, how they work around systems, which assumptions are projections, and how user-centered evidence should influence decisions.

## Advanced strategist-facing capabilities

- Empathic inquiry quality assessment
- Projection-risk diagnostics
- User/stakeholder field mapping
- Observation and workaround synthesis
- Journey friction and accumulated-burden scoring
- Unmet-need detection and prioritization
- Stated-preference versus behavior comparison
- Reframing quality scoring
- Multi-stakeholder burden-shift review
- Ethical empathy and participation legitimacy review
- Systems-aware user research diagnostics
- Prototype-test planning from user evidence
- Decision-linkage and insight-to-action scoring
- Institutional user-insight memory records
- SQL schemas for contexts, stakeholders, observations, journeys, pain points, unmet needs, preferences, behaviors, frames, prototypes, tests, ethics, decisions, and learning records
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible empathy and user-centered ideation analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/empathy_user_centered_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_empathy_user_centered_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accessibility review, accountable governance, or participatory judgment.
