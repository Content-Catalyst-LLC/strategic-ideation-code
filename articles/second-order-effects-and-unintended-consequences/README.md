# Second-Order Effects and Unintended Consequences

This article folder contains an advanced, strategist-facing companion scaffold for **"Second-Order Effects and Unintended Consequences."**

The repository treats second-order reasoning as a professional strategic discipline for analyzing indirect, delayed, adaptive, cascading, and unintended consequences of intervention in complex systems. It supports intervention diagnostics, propagation mapping, feedback-loop review, adaptive actor analysis, burden-shift analysis, incentive distortion scoring, fragility assessment, scenario stress testing, early-warning indicators, learning-loop design, and decision-memory records.

## Why this exists

Strategic interventions rarely end with their first-order result. They alter incentives, feedback loops, interpretation, trust, burdens, dependencies, and future option space. This scaffold helps strategists avoid false first-order success, policy resistance, metric distortion, fragility creation, burden shifting, adaptive workarounds, and delayed system harm.

## Advanced strategist-facing capabilities

- Second-order effect profile scoring
- First-order versus long-term outcome comparison
- Propagation pathway diagnostics
- Feedback-loop and policy-resistance review
- Behavioral adaptation and incentive distortion scoring
- Burden-shift and externality review
- Fragility and resilience erosion analysis
- Scenario stress testing for unintended consequences
- Early-warning indicator and revision-trigger design
- Learning-loop and decision-memory governance
- SQL schemas for interventions, pathways, actors, incentives, feedback loops, delays, burdens, risks, signals, triggers, and decision records
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible second-order analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/second_order_effects_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_second_order_analytics.py
```
