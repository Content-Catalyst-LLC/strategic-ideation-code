# Strategic Ideation Modeling Principles

## 1. Start with problem framing
No idea can be evaluated well if the problem is poorly framed.

## 2. Separate generation from evaluation
Premature evaluation can kill useful novelty; unstructured generation can produce noise.

## 3. Make criteria explicit
Evaluation criteria reveal strategic values and assumptions.

## 4. Treat scoring as provisional
Scores help comparison but cannot replace judgment.

## 5. Track assumptions
Every strategic idea depends on assumptions about systems, users, institutions, futures, and resources.

## 6. Connect ideas to implementation
A strategic idea should eventually connect to pathways, roles, milestones, feedback, and learning.

## 7. Preserve ethical judgment
Ask who benefits, who bears risk, and whose knowledge shaped the idea.
