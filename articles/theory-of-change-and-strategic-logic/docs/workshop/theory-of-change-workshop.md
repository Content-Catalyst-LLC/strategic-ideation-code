# Theory of Change and Strategic Logic Workshop

## Purpose

Help a strategy team connect a strategic idea to a plausible, testable, ethically responsible pathway from action to outcome.

## Suggested duration

2 to 3 hours.

## Participants

- Strategy lead
- Facilitator
- Evaluation or evidence lead
- Stakeholder researcher
- Systems thinker
- Implementation owner
- Ethics or governance reviewer
- Decision-memory owner

## Agenda

### 1. State the problem frame

Define the problem, boundary, stakeholders, and system context.

### 2. State the strategic idea

Describe the proposed intervention clearly enough to test.

### 3. Name the mechanism

Explain how the idea is expected to produce change.

### 4. Map the pathway

Connect inputs, activities, outputs, outcomes, impact, and learning.

### 5. Map actors

Identify who must authorize, participate, implement, adopt, resist, benefit, or bear burden.

### 6. Map assumptions

For each causal link, ask what must be true.

### 7. Review evidence

Identify what evidence supports or challenges each link.

### 8. Add system response

Map feedback loops, delays, adaptation, burden shifts, metric gaming, and context dependence.

### 9. Design prototype tests

Prioritize tests for weak, critical, and uncertain links.

### 10. Define learning loops

Record what evidence changes, pauses, scales, or stops the strategy.

## Output

- theory-of-change map
- mechanism statement
- causal link risk table
- assumption register
- evidence plan
- actor response map
- system feedback review
- outcome sequence map
- prototype test plan
- revision trigger log
- decision-memory record
