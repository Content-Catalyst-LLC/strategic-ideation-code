# Strategist Guide

This scaffold supports theory-of-change and strategic logic work through ten recurring questions:

1. **Problem frame:** What condition are we trying to change?
2. **Strategic idea:** What action is being proposed?
3. **Mechanism:** How is the action expected to create change?
4. **Pathway:** What is the sequence from inputs to activities, outputs, outcomes, and impact?
5. **Actors:** Who must respond, participate, implement, or authorize?
6. **Assumptions:** What must be true for each link to work?
7. **Evidence:** What evidence validates or challenges each link?
8. **System response:** What feedback, delay, burden shift, or adaptation might occur?
9. **Prototype test:** How can weak links be tested before scaling?
10. **Learning loop:** What evidence changes the strategy?

## Recommended workflow

### Step 1: Score strategic logic

Use `strategic_ideas.csv` to compare problem frame quality, mechanism clarity, strategic alignment, implementation feasibility, stakeholder legitimacy, system complexity, learning value, and reversibility.

### Step 2: Score causal link risk

Use `theory_links.csv` to identify weak links between activities, participation, behavior, outcomes, impact, and revision.

### Step 3: Map assumptions

Use `assumptions.csv` to locate load-bearing beliefs in each causal link.

### Step 4: Match evidence to claims

Use `evidence_sources.csv` to check reliability, relevance, transferability, timeliness, bias risk, coverage, and interpretation quality.

### Step 5: Analyze actor response

Use `actor_response.csv` to test whether stakeholders and implementers are likely to respond as expected.

### Step 6: Review system feedback

Use `system_feedback.csv` to identify feedback loops, delays, adaptation, burden shift, metric gaming, and context dependence.

### Step 7: Sequence outcomes

Use `outcome_sequence.csv` to prevent premature impact claims and clarify what evidence should appear when.

### Step 8: Design prototypes

Use `prototype_tests.csv` to align prototypes with weak causal links.

### Step 9: Build implementation learning loops

Use `implementation_learning.csv` to connect evidence, governance, revision capacity, stakeholder visibility, and decision memory.

### Step 10: Define revision triggers

Use `revision_triggers.csv` to connect evidence to decisions.
