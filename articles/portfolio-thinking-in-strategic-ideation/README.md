# Portfolio Thinking in Strategic Ideation

This article folder contains an advanced, strategist-facing companion scaffold for **"Portfolio Thinking in Strategic Ideation."**

The repository treats strategic idea portfolios as governed learning systems: balanced sets of ideas that distribute risk, preserve option value, protect exploration, support current performance, respect capacity constraints, sequence dependencies, and make ethical tradeoffs visible.

## Why this exists

Organizations often evaluate ideas one at a time. Portfolio thinking asks what the whole set of ideas does: how it balances incremental work, exploration, transformation, resilience, legitimacy, learning, option value, capacity demand, dependencies, and strategic fit.

## Advanced strategist-facing capabilities

- Strategic idea portfolio diagnostics
- Portfolio role mapping
- Risk-return-learning comparison
- Option-value review
- Time-horizon balance
- Capacity load analysis
- Dependency and sequencing review
- Exploration/exploitation balance
- Ethical burden and power review
- Portfolio governance and pruning rules
- Decision-memory documentation
- SQL schema for ideas, roles, evidence, risk, dependencies, capacity, ethics, governance, and memory
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible portfolio analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/portfolio_thinking_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_portfolio_analytics.py
```
