# Strategic Idea Portfolio Workshop

## Purpose

Help a team turn a scattered set of ideas into a balanced, governed, learning-oriented strategic portfolio.

## Suggested duration

3 to 4 hours.

## Participants

- Strategy lead
- Decision owner
- Finance or resource lead
- Product, policy, program, or portfolio owner
- Implementation lead
- Risk/governance representative
- Stakeholder or user representative
- Ethics reviewer
- Challenge-role participant
- Decision-memory owner

## Agenda

### 1. Build the idea inventory

List active, proposed, paused, exploratory, and legacy ideas.

### 2. Assign portfolio roles

Classify ideas by role: core improvement, exploration, option preservation, transformation, resilience, legitimacy, foresight, capability building, ethics governance, or legacy review.

### 3. Map value and risk

Compare impact, risk, learning value, option value, strategic fit, capacity demand, and ethical resilience.

### 4. Review time horizons

Check whether the portfolio is overconcentrated in immediate, short-term, medium-term, or long-term value.

### 5. Test capacity

Compare ambition against budget, people, technical capacity, governance bandwidth, leadership attention, and stakeholder patience.

### 6. Map dependencies

Identify enabling foundations, sequencing needs, readiness gaps, and path dependencies.

### 7. Review ethics and power

Ask whose ideas are included, whose needs are excluded, who benefits, who bears burden, and whose voice counts.

### 8. Define governance

Set entry rules, evidence standards, review cadence, pruning rules, escalation paths, and decision memory.

## Output

- idea inventory
- portfolio role map
- risk-learning matrix
- capacity load review
- dependency and sequencing map
- time-horizon balance map
- ethics and power review
- portfolio governance protocol
- decision memory record
