# Implementation Pathways and Strategic Sequencing Workshop

## Purpose

Help a team determine whether a strategy is ready to move into implementation, what must happen first, what should be staged, what should wait, and what evidence should trigger resequencing.

## Suggested duration

3 to 4 hours.

## Outputs

- pathway purpose statement
- stage map
- dependency map
- readiness-gate checklist
- capability-building plan
- capacity-load assessment
- reversibility and lock-in review
- timing-window map
- resequencing protocol
- ethics and power review
- decision-memory record
