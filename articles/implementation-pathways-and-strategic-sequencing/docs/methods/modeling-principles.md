# Modeling Principles for Implementation Pathways and Strategic Sequencing

1. Sequence is strategic, not merely administrative.
2. A pathway is more than a project plan.
3. Readiness conditions should precede high-commitment stages.
4. Dependencies should be made explicit before action begins.
5. Capability-building should often precede scaling.
6. Commitment should match evidence strength and reversibility.
7. Capacity load can make individually sound initiatives fail together.
8. Timing windows require balancing urgency with readiness.
9. Feedback should allow resequencing.
10. Ethical sequencing asks who gets voice before commitment and who bears burden after it.
