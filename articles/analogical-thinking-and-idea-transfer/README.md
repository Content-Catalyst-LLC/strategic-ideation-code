# Analogical Thinking and Idea Transfer

This article folder contains an advanced, strategist-facing companion scaffold for **"Analogical Thinking and Idea Transfer."**

The repository treats analogy as disciplined structural transfer: identifying a source domain, defining a target problem, mapping relational correspondence, testing adaptation quality, reviewing stakeholder legitimacy, and preserving decision memory around transferred ideas.

## Why this exists

Organizations use analogy constantly, but often weakly. They benchmark peers, borrow admired models, imitate visible success, invoke historical comparisons, use biological metaphors, or import fashionable frameworks without testing whether the underlying structure actually maps.

This scaffold helps strategists distinguish deep structural transfer from surface resemblance, prestige borrowing, context neglect, and power-blind imitation.

## Advanced strategist-facing capabilities

- Source-target analogical mapping
- Structural-fit and functional-fit scoring
- Surface-distraction risk analysis
- Context-sensitivity and adaptation-quality review
- Dynamic compatibility testing for complex systems
- Stakeholder legitimacy and burden visibility checks
- Rival analogy comparison
- Analogical transfer hypothesis tracking
- Evidence and failure-mode review
- Decision-memory templates for transferred ideas
- SQL schemas for source domains, target domains, mappings, transfer hypotheses, evidence, stakeholder review, and decisions
- Optional advanced analytics with pandas and matplotlib
- Multi-language examples for reproducible analogical analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/analogical_transfer_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_analogical_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
