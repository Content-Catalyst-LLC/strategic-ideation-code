# Leverage Points in Systems Change

This article folder contains an advanced, strategist-facing companion scaffold for **"Leverage Points in Systems Change."**

The repository treats leverage-point analysis as a professional discipline for identifying where interventions enter a complex system and whether they affect parameters, buffers, delays, feedback loops, information flows, rules, incentives, system goals, paradigms, tipping thresholds, and learning loops.

## Why this exists

Strategic interventions often fail because they are placed where problems are visible rather than where systems are structurally sensitive. This scaffold helps strategists compare shallow and deep leverage points, diagnose feedback and information-flow opportunities, review rules and incentives, surface operating goals and paradigms, evaluate tipping dynamics, and design governance for high-leverage intervention.

## Advanced strategist-facing capabilities

- Leverage-depth scoring and intervention classification
- Structural sensitivity and feedback influence diagnostics
- Information-flow and visibility analysis
- Rule and incentive mapping
- System-goal and operating-goal diagnosis
- Paradigm and mental-model review
- Timing, delay, and threshold analysis
- Positive tipping and self-reinforcing change review
- Unintended-consequence and governance-need scoring
- Early-warning indicators and revision-trigger design
- Decision-memory records for leverage hypotheses
- SQL schemas for systems, leverage points, feedback loops, information flows, rules, incentives, goals, paradigms, scenarios, indicators, learning loops, and decisions
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible leverage-point strategy analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/leverage_point_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_leverage_analytics.py
```

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
