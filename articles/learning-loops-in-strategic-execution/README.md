# Learning Loops in Strategic Execution

This article folder contains an advanced, strategist-facing companion scaffold for **Learning Loops in Strategic Execution**.

The repository treats strategic execution as a learning system. It supports learning loop diagnostics, feedback-quality assessment, assumption review, evidence-confidence scoring, after-action review, strategic retrospective design, decision-memory documentation, governance authority scoring, learning closure analysis, knowledge scaling, psychological safety review, ethical learning review, and strategic learning simulation.

## Advanced strategist-facing capabilities

- Strategic learning loop diagnostics
- Feedback-quality assessment
- Assumption register and assumption-testing review
- Evidence-confidence scoring
- After-action review and strategic retrospective design
- Single-loop, double-loop, and triple-loop learning analysis
- Learning closure assessment
- Governance authority and decision-gate review
- Decision-memory documentation
- Knowledge scaling and reuse review
- Psychological safety and candor assessment
- Ethical learning and power review
- Learning debt simulation
- SQL schema for assumptions, feedback, reviews, lessons, decisions, revision triggers, governance, evidence, ethics, and knowledge reuse
- Python, R, Julia, SQL, Rust, Go, C++, Fortran, and C examples

## Quick start

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/learning_loop_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_learning_analytics.py
```

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for executive judgment, stakeholder engagement, ethical review, legal review, domain expertise, accountable governance, implementation expertise, labor consultation, or responsible institutional change.
