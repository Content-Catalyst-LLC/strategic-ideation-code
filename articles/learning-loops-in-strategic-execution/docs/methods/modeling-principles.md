# Modeling Principles for Learning Loops in Strategic Execution

1. Feedback is not the same as learning.
2. A learning loop is closed only when evidence changes judgment, decision, action, or memory.
3. Execution tests assumptions whether or not those assumptions are explicit.
4. Single-loop learning corrects action; double-loop learning revises assumptions; triple-loop learning improves the learning system.
5. Metrics must be interpreted as evidence rather than treated as truth.
6. Governance converts learning into choice.
7. Decision memory prevents lessons from disappearing across people, teams, and time.
8. Psychological safety enables candor, but accountability is needed for closure.
9. Knowledge architecture determines whether lessons scale.
10. Ethical learning asks whose evidence counts and whose burden becomes visible.
