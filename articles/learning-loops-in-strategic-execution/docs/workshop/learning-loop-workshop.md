# Learning Loops in Strategic Execution Workshop

## Purpose

Help a team determine whether execution evidence is improving strategic judgment or merely producing reports.

## Suggested duration

3 to 4 hours.

## Outputs

- learning purpose statement
- assumption register
- evidence map
- evidence-confidence review
- interpretation brief
- governance authority map
- action and follow-up plan
- decision-memory record
- knowledge reuse and tagging plan
- ethics and power review
