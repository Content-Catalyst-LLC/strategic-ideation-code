# Strategist Guide

This scaffold supports learning loop and strategic execution analysis through ten recurring questions:

1. What must execution teach the strategy?
2. Which assumptions are being tested?
3. What evidence is reliable, timely, valid, and contextually relevant?
4. Who interprets the evidence?
5. Who has authority to act on the learning?
6. Does learning change decisions, resources, sequencing, incentives, or memory?
7. Are lessons preserved in a reusable decision-memory structure?
8. Can people report error, harm, weak signals, and dissent honestly?
9. Can lessons travel across teams, portfolios, and time?
10. Whose evidence counts, whose burden is visible, and who can challenge the lesson?

Recommended workflow:

- Run `python3 python/learning_loop_diagnostics.py`
- Review `outputs/tables/learning_loop_scores.csv`
- Review `outputs/tables/feedback_quality_scores.csv`
- Review `outputs/tables/assumption_review_scores.csv`
- Review `outputs/tables/governance_learning_scores.csv`
- Review `outputs/tables/knowledge_scaling_scores.csv`
- Review `outputs/tables/ethics_power_scores.csv`
- Use the generated markdown report for workshop discussion.
