# Abductive Reasoning Workshop

## Purpose

Help a strategy team move from ambiguous observations to rival strategic hypotheses, evidence pathways, and revision-ready decisions.

## Suggested duration

2 to 3 hours.

## Participants

- Strategy lead
- Facilitator
- Evidence or analytics lead
- Domain experts
- Systems thinker
- Stakeholder representative or design researcher
- Implementation owner
- Decision-memory owner

## Agenda

### 1. Name the observation

State what requires explanation without jumping to a solution.

### 2. Identify the frame

Ask whether the observation is being interpreted as awareness, trust, access, incentives, systems behavior, legitimacy, learning, or implementation.

### 3. Generate rival hypotheses

Create at least three plausible explanations, including a stakeholder-centered explanation and a systems explanation.

### 4. State mechanisms

For each hypothesis, explain how the mechanism would produce the observed pattern.

### 5. Define evidence

Specify what should be visible if each hypothesis is true.

### 6. Define disconfirmation

Specify what would weaken or replace each hypothesis.

### 7. Match commitment

Decide whether the hypothesis justifies monitoring, research, prototype, pilot, scaling, or archive.

### 8. Preserve decision memory

Record rejected, deferred, and revised hypotheses with reopen triggers.

## Output

- observation statement
- frame comparison
- rival hypothesis set
- mechanism map
- evidence pathway
- disconfirmation plan
- commitment-level decision
- revision trigger
- decision-memory record
