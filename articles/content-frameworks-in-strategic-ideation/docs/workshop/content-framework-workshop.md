# Content Frameworks in Strategic Ideation Workshop

## Purpose

Help a team determine whether its content frameworks improve strategic judgment or simply standardize presentation.

## Suggested duration

3 to 4 hours.

## Outputs

- framework purpose statement
- content type inventory
- conceptual hierarchy map
- required field schema
- evidence and assumption standard
- narrative coherence review
- decision relevance map
- reusable component library
- framework stewardship model
- ethics and power review
