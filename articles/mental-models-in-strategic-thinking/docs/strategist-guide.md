# Strategist Guide

This scaffold is designed for professional mental-model analysis in strategic thinking. It supports seven recurring strategy questions:

1. **Representation:** What model of reality is guiding this strategy?
2. **Causality:** What does the model assume causes change?
3. **Evidence:** What evidence does the model admit, filter, or ignore?
4. **Plurality:** Which alternative models are missing?
5. **Lock-in:** Which institutional artifacts protect the current model?
6. **Revision:** What evidence would force the model to change?
7. **Legitimacy:** Whose experience, burden, or knowledge is invisible?

## Recommended workflow

### Step 1: Score model profiles

Use `mental_model_profiles.csv` and the Python workflow to compare model richness, flexibility, plurality, revision capacity, ethical visibility, stakeholder visibility, and evidence responsiveness.

### Step 2: Audit causal frames

Use `causal_frames.csv` to test whether the model matches the causal structure of the environment.

### Step 3: Review institutional artifacts

Use `institutional_artifacts.csv` to identify dashboards, metrics, plans, budgets, and routines that encode outdated or narrow models.

### Step 4: Map disconfirming evidence

Use `evidence_feedback.csv` to identify evidence that should trigger model revision.

### Step 5: Prioritize model audits

Use `model_audit_items.csv` to decide which audit questions require immediate review.

### Step 6: Stress-test under scenarios

Use `scenario_stress_tests.csv` to identify models likely to fail under complexity, legitimacy crisis, adoption resistance, or environmental discontinuity.

## Professional facilitation questions

- What model is making this action appear sensible?
- What causal assumption is doing the most work?
- What does this model fail to see?
- What evidence are we treating as anomaly rather than signal?
- Which institutional artifact protects the current model?
- Which stakeholders are invisible under this model?
- What scenario would expose the model’s limits?
