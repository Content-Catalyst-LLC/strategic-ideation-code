# Mental Models in Strategic Thinking

This article folder contains an advanced, strategist-facing companion scaffold for **"Mental Models in Strategic Thinking."**

The repository treats mental models as the cognitive infrastructure of strategy: the representations through which strategists interpret environments, infer causality, filter evidence, imagine futures, diagnose uncertainty, and choose action.

## Why this exists

Strategy teams rarely decide from raw facts. They decide through models: causal assumptions, professional habits, dashboards, institutional categories, historical analogies, risk frames, and future imaginaries. Strategic failure often occurs when the governing model is too narrow, too linear, too institutionally protected, too ethically blind, or too resistant to feedback.

This scaffold provides practical tools for auditing, comparing, revising, and governing strategic mental models.

## Advanced strategist-facing capabilities

- Mental-model profile scoring
- Causal-frame adequacy review
- Model monoculture and plurality diagnostics
- Institutional lock-in assessment
- Evidence interpretation and disconfirmation mapping
- Feedback-to-model revision routing
- Scenario stress testing for mental models
- Ethical visibility and stakeholder-blindness review
- Decision-memory templates for model revision
- SQL schemas for model audits and learning governance
- Optional advanced analytics with pandas and matplotlib
- Multi-language examples for reproducible mental-model analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/mental_model_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_model_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
