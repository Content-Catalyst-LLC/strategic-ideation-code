# Strategist Guide

This scaffold supports strategic communication and conceptual coherence analysis through ten recurring questions:

1. What strategic work should this communication perform?
2. Which core concepts carry strategic meaning?
3. Are concepts defined with boundaries, mechanisms, examples, exclusions, and version history?
4. Does the narrative preserve problem, stakes, insight, direction, mechanism, evidence, choice, and consequence?
5. Are claims traceable to evidence, confidence levels, assumptions, uncertainty, and counterevidence?
6. Can audience-specific versions adapt without distorting core meaning?
7. Does communication reflect actual decisions, rationale, tradeoffs, owners, timelines, and revision triggers?
8. Can implementation teams translate the communication into roles, routines, resources, measures, and action?
9. How are audience interpretations, questions, confusion, dissent, and resistance captured?
10. Whose meaning, burden, dissent, and accountability remain visible?

Recommended workflow:

- Run `python3 python/communication_coherence_diagnostics.py`
- Review `outputs/tables/communication_profile_scores.csv`
- Review `outputs/tables/concept_definition_scores.csv`
- Review `outputs/tables/claim_evidence_scores.csv`
- Review `outputs/tables/audience_adaptation_scores.csv`
- Review `outputs/tables/decision_alignment_scores.csv`
- Review `outputs/tables/governance_ethics_scores.csv`
- Use the generated markdown report for workshop discussion.
