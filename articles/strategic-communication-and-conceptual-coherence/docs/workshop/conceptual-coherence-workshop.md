# Strategic Communication and Conceptual Coherence Workshop

## Purpose

Help a team determine whether strategic communication preserves meaning across audiences, documents, decisions, implementation contexts, feedback loops, and time.

## Suggested duration

3 to 4 hours.

## Outputs

- communication purpose statement
- core concept inventory
- concept definition and boundary sheet
- narrative coherence map
- claim-evidence register
- audience adaptation matrix
- decision-communication alignment review
- implementation meaning test
- interpretation feedback log
- ethics and power review
