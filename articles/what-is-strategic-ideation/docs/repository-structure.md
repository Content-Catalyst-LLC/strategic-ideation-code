# Repository Structure

This article scaffold is organized to support reproducible examples across several languages.

- `python/` contains the main synthetic-data scoring workflow.
- `r/` contains a portfolio comparison and revision-flag workflow.
- `julia/` contains scenario-comparison logic.
- `sql/` contains normalized schema examples for ideas, criteria, assumptions, evaluations, prototypes, and implementation records.
- `rust/`, `go/`, `cpp/`, `fortran/`, and `c/` provide small diagnostics or scoring examples.
- `data/raw/` contains synthetic source datasets.
- `data/processed/` is reserved for generated processed datasets.
- `outputs/figures/` and `outputs/tables/` are reserved for generated outputs.
- `notebooks/` is reserved for exploratory notebook versions.
