# Implementation Governance

Implementation governance prevents strategy from becoming symbolic rhetoric.

## Requirements

- translated work map
- owner clarity
- decision rights
- resource commitments
- incentive and metric audit
- coordination map
- feedback and adaptation protocol
- ethics and burden review
- decision memory

## Anti-failure rules

- Do not announce strategy without resources.
- Do not rely on communication when incentives contradict the strategy.
- Do not confuse alignment with compliance.
- Do not punish responsible learning.
- Do not ignore implementation burden.
- Do not forget decision memory.
