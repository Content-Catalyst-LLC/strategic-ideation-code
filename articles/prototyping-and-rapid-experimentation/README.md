# Prototyping and Rapid Experimentation

This article folder contains an advanced, strategist-facing companion scaffold for **"Prototyping and Rapid Experimentation."**

The repository treats prototypes as structured questions posed to reality and experiments as disciplined learning systems. It supports assumption mapping, hypothesis design, prototype-fit review, experiment scoring, evidence-quality review, user-validation analysis, iteration tracking, systems-impact interpretation, ethical experiment governance, decision-linkage scoring, learning-efficiency modeling, and institutional experiment-memory records.

## Why this exists

Strategic ideas often remain too long in language, decks, matrices, and consensus rituals before they meet users, operations, incentives, constraints, timing, context, or system feedback. This scaffold helps teams test important assumptions early, cheaply, and responsibly before sunk costs and institutional commitment make revision harder.

## Advanced strategist-facing capabilities

- Prototype portfolio review
- Assumption criticality mapping
- Hypothesis and learning-target design
- Prototype fidelity-fit scoring
- Experiment quality diagnostics
- Evidence-quality and interpretation review
- User-validation and behavioral evidence assessment
- Iteration discipline and learning-memory tracking
- Speed, cost, reversibility, and learning-efficiency modeling
- Systems-impact and scale-readiness review
- Ethical governance and participant-risk review
- Decision-linkage and evidence-to-action scoring
- SQL schemas for prototypes, assumptions, hypotheses, experiments, participants, evidence, ethics, systems effects, decisions, iterations, and learning records
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible prototyping and rapid experimentation analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/prototyping_experimentation_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_prototyping_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for user research, ethical review, domain expertise, accessibility testing, accountable governance, participatory design, or responsible implementation judgment.
