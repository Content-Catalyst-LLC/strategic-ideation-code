# Design Thinking Foundations

This article folder contains an advanced, strategist-facing companion scaffold for **"Design Thinking Foundations."**

The repository treats design thinking as a professional strategic capability for human-centered inquiry, problem framing and reframing, divergent and convergent ideation, prototype learning, testing, systems-aware design, ethical review, decision linkage, and institutional learning.

## Why this exists

Design thinking is often reduced to workshops, sticky notes, and generic creativity rituals. This scaffold treats it as a disciplined method of strategic inquiry under uncertainty. It helps strategists examine whether design thinking is actually improving problem understanding, stakeholder insight, prototype learning, evidence quality, decision-making, systems awareness, ethical responsibility, and institutional learning.

## Advanced strategist-facing capabilities

- Design thinking capability profile scoring
- Empathy depth and stakeholder inquiry review
- Problem framing and reframing diagnostics
- Idea portfolio and divergence/convergence review
- Prototype learning value analysis
- Test quality and evidence fit review
- Systems-aware design diagnostics
- Ethical design and participation review
- Decision-linkage scoring
- Superficial-workshop risk detection
- Institutional learning and decision-memory records
- SQL schemas for challenges, stakeholders, observations, journey maps, frames, ideas, prototypes, tests, evidence, revisions, decisions, and learning records
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible design thinking analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/design_thinking_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_design_thinking_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
