# Modeling Principles for Design Thinking Foundations

## 1. Treat design thinking as inquiry, not theater

A useful design process changes what the team understands, tests, decides, and remembers.

## 2. Empathy is evidence work

Empathy should produce evidence about lived experience, constraints, trust, burden, workarounds, and meaning.

## 3. Framing is a strategic act

The problem frame determines the option space. Reframing should be documented and tested.

## 4. Prototypes are learning instruments

A prototype is valuable when it tests an assumption that matters for a decision.

## 5. Testing is not validation by default

Positive feedback does not automatically prove adoption, implementation success, or impact.

## 6. Systems awareness prevents local fixes from creating broader harm

Design thinking should include feedback loops, burden shifts, incentives, delays, and unintended consequences.

## 7. Ethical design requires attention to power

Participation must affect decisions. Otherwise human-centered language can become symbolic.

## 8. Institutional memory makes design learning durable

Teams should preserve observations, frames, assumptions, prototypes, evidence, decisions, and revisions.
