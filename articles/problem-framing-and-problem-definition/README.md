# Problem Framing and Problem Definition

This article folder contains an advanced, strategist-facing companion scaffold for **"Problem Framing and Problem Definition."**

The repository treats problem framing as a strategic discipline: the construction, comparison, testing, revision, and governance of problem representations before solution generation begins. It supports frame-quality diagnostics, boundary audits, stakeholder frame mapping, causal-depth review, assumption transparency, frame-origin analysis, reframing triggers, idea-space expansion modeling, decision memory, and multi-language reproducible workflows.

## Why this exists

Strategic ideas are downstream from problem representation. If the frame is weak, even rigorous analysis can optimize the wrong reality. This scaffold helps strategists diagnose whether a problem definition is too narrow, administratively convenient, politically protected, stakeholder-blind, causally shallow, over-simplified, or locked into institutional habit.

## Advanced strategist-facing capabilities

- Problem-framing profile scoring
- Frame-origin and institutional lock-in diagnostics
- Boundary breadth and boundary-risk audits
- Stakeholder frame comparison and hidden-burden review
- Causal-depth and mechanism-quality scoring
- Assumption transparency review
- Alternative-frame comparison matrix
- Frame-to-idea-space expansion modeling
- Reframing trigger and decision-memory design
- SQL schemas for problems, frames, boundaries, stakeholders, assumptions, evidence, causal models, reframing events, decisions, and idea-space outputs
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible framing analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/problem_framing_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_framing_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
