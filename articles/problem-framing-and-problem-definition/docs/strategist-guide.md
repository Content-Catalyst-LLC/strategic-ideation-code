# Strategist Guide

This scaffold is designed for professional problem-framing work. It supports ten recurring questions:

1. **Current frame:** How is the problem currently defined?
2. **Frame origin:** Where did this definition come from?
3. **Boundary:** What is included and excluded?
4. **Stakeholders:** Who defines the problem differently?
5. **Causal story:** What mechanism is assumed to produce the problem?
6. **Assumptions:** What must be true for this frame to hold?
7. **Alternatives:** What rival frames should be compared?
8. **Success criteria:** What would count as improvement?
9. **Reframing trigger:** What evidence would reopen the definition?
10. **Memory:** What should be preserved for future learning?

## Recommended workflow

### Step 1: Score problem-framing quality

Use `problem_frames.csv` and the Python diagnostic to assess boundary breadth, stakeholder inclusion, systems awareness, causal depth, assumption clarity, reframing capacity, actionability, institutional lock-in risk, and political convenience risk.

### Step 2: Review frame origin

Use `frame_origins.csv` to detect whether the problem definition comes from authority, metrics, legacy categories, stakeholder evidence, frontline evidence, or independent diagnosis.

### Step 3: Audit boundaries

Use `boundary_audit.csv` to determine whether the problem definition includes stakeholders, downstream effects, externalities, implementation realities, time horizons, and hidden dependencies.

### Step 4: Compare stakeholder definitions

Use `stakeholder_frames.csv` to identify burden, trust, agency, legitimacy, conflict, participation, and hidden harm.

### Step 5: Examine causal depth

Use `causal_models.csv` to test whether the frame names symptoms or explains mechanisms.

### Step 6: Audit assumptions

Use `assumption_audit.csv` to prioritize high-importance, high-uncertainty assumptions for testing.

### Step 7: Compare alternatives

Use `alternative_frames.csv` to compare rival frames before committing to a single problem definition.

### Step 8: Set reframing triggers

Use `reframing_triggers.csv` to define evidence that would reopen the problem definition.
