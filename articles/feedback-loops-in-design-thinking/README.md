# Feedback Loops in Design Thinking

This article folder contains an advanced, strategist-facing companion scaffold for **"Feedback Loops in Design Thinking."**

The repository treats feedback loops as recursive learning structures that connect signal generation, interpretation, adjustment, decision authority, ethics, systems awareness, and institutional memory. It supports feedback-loop diagnostics, signal-quality review, interpretation-capacity scoring, adjustment-pathway mapping, user-feedback analysis, temporal learning review, systems-impact assessment, ethical feedback governance, noisy-churn risk scoring, decision-linkage review, and institutional feedback-memory records.

## Why this exists

Design systems often collect feedback without learning from it. Signals are scattered across surveys, analytics, support queues, interviews, frontline observations, accessibility reviews, community input, and operational metrics. This scaffold helps teams convert feedback into responsible strategic learning rather than noise, metric gaming, performative responsiveness, or extractive data collection.

## Advanced strategist-facing capabilities

- Feedback-system profile scoring
- Signal-quality diagnostics
- Interpretation-capacity review
- Adjustment-pathway and decision-authority mapping
- User-feedback and experiential insight analysis
- Temporal learning and delayed-consequence review
- Positive, reinforcing, balancing, and stabilizing loop review
- Noisy-churn and overreaction risk scoring
- Systems-impact and burden-shift assessment
- Ethical feedback governance
- Decision-linkage and revision-trigger scoring
- Institutional feedback-memory records
- SQL schemas for feedback systems, signals, users, interpretations, adjustments, decisions, ethics reviews, metrics, learning records, and revision triggers
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible feedback-loop analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/feedback_loop_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_feedback_loop_analytics.py
```

They are not a substitute for user research, ethical review, domain expertise, accessibility testing, accountable governance, participatory design, or responsible implementation judgment.
