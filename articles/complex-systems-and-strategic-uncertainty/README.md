# Complex Systems and Strategic Uncertainty

This article folder contains an advanced, strategist-facing companion scaffold for **"Complex Systems and Strategic Uncertainty."**

The repository treats complexity-aware strategy as a professional discipline for navigating environments shaped by interdependence, nonlinear response, feedback loops, adaptive actors, emergence, path dependence, deep uncertainty, scenario divergence, and learning-loop requirements.

## Why this exists

Complex systems make strategy difficult not only because information is incomplete, but because the system itself changes through interaction, adaptation, feedback, and emergent behavior. This scaffold helps strategists diagnose when conventional planning is insufficient and when strategy should shift toward robust options, adaptive pathways, scenario testing, early-warning indicators, learning loops, and decision memory.

## Advanced strategist-facing capabilities

- Complexity-profile scoring for strategic environments
- Structural uncertainty and deep-uncertainty diagnostics
- Feedback-loop and recursive-causality review
- Nonlinearity and sensitivity scoring
- Adaptive actor and moving-target analysis
- Path-dependence and lock-in review
- Scenario robustness and stress-test workflows
- Adaptive option portfolio scoring
- Early-warning indicator and signal review
- Learning-loop and decision-memory design
- SQL schemas for systems, actors, feedback loops, uncertainty drivers, scenarios, assumptions, options, interventions, indicators, learning loops, and decision records
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible complexity-aware strategy analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/complexity_strategy_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_complexity_analytics.py
```
