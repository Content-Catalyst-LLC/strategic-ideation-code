# Complexity Strategy Governance

Complexity-aware strategy requires governance that connects uncertainty, scenarios, adaptive options, early-warning indicators, learning loops, and decision memory.

## Governance requirements

- Complexity classification
- Uncertainty-driver review
- Feedback-loop review
- Adaptive actor review
- Path-dependence review
- Scenario robustness matrix
- Adaptive option portfolio
- Early-warning indicator set
- Learning-loop design
- Decision-memory record

## Review cadence

- Before ideation: classify environment and complexity dimensions
- Before option selection: review uncertainty drivers, feedback, adaptation, and path dependence
- Before implementation: stress-test scenarios and select adaptive options
- During implementation: monitor early-warning indicators
- After implementation: update scenarios, options, assumptions, and decision memory
- Quarterly: review robustness gaps and option portfolio

## Anti-failure rules

- Do not treat complex environments as merely complicated.
- Do not rely on a single forecast where structural uncertainty is high.
- Do not scale before reviewing feedback and adaptation.
- Do not mistake large interventions for high-leverage interventions.
- Do not invoke complexity without naming mechanisms and evidence.
- Do not let implementation evidence fail to update strategy.
