# Complexity-Aware Strategy Workshop

## Purpose

Help a strategy team determine whether a strategic environment requires conventional planning, complexity-aware planning, adaptive pathways, or scenario-based learning.

## Suggested duration

2 to 3 hours.

## Participants

- Strategy lead
- Facilitator
- Systems thinker
- Foresight practitioner
- Stakeholder researcher
- Implementation owner
- Data or evidence lead
- Governance owner
- Decision-memory owner

## Agenda

### 1. Classify the environment

Discuss whether the challenge is simple, complicated, complex, or chaotic.

### 2. Map complexity dimensions

Assess interdependence, nonlinearity, feedback, adaptation, emergence, path dependence, boundary ambiguity, and deep uncertainty.

### 3. Identify uncertainty drivers

Separate volatility, ambiguity, model uncertainty, probability instability, value contestation, and actor reflexivity.

### 4. Map feedback and adaptation

Identify loops and likely actor responses.

### 5. Review path dependence

Name legacy constraints, lock-in risks, transition costs, and option closures.

### 6. Stress-test scenarios

Compare how proposed strategies perform across plausible futures.

### 7. Design adaptive options

Build no-regret moves, low-regret experiments, hedges, staged commitments, and adaptive pathways.

### 8. Define early-warning indicators

Connect signals to decision thresholds and revision triggers.

### 9. Preserve decision memory

Record assumptions, scenarios, options, evidence, and reopen triggers.

## Output

- complexity classification
- uncertainty-driver review
- feedback-loop map
- adaptive actor review
- path-dependence review
- scenario robustness matrix
- adaptive option portfolio
- early-warning indicator set
- learning-loop plan
- decision-memory record
