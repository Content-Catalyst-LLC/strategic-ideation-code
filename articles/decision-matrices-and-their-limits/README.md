# Decision Matrices and Their Limits

Advanced strategist-facing companion scaffold for **Decision Matrices and Their Limits**.

This folder treats decision matrices as deliberation tools, not decision machines. It includes workflows for criteria design, weight sensitivity, evidence confidence, rank stability, false precision warnings, scenario scoring, ethical threshold review, governance, and decision memory.

## Quick start

```bash
./run_all.sh
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_matrix_analytics.py
```
