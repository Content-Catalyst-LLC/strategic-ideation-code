# Modeling Principles for Heuristics in Strategic Ideation

## 1. Treat heuristics as search-compression mechanisms

Heuristics make strategy possible under bounded rationality, but every compression changes what is searched.

## 2. Diagnose the search process before ranking ideas

A rigorous evaluation process cannot compensate for an idea space narrowed too early.

## 3. Separate speed from closure

Fast idea generation is useful when it begins exploration. It is dangerous when it ends exploration prematurely.

## 4. Score heuristic diversity

A strong strategic process uses multiple shortcut families: framing, analogy, stakeholder, systems, first-principles, scenario, feasibility, and learning heuristics.

## 5. Audit institutional shortcuts

Templates, dashboards, approval rules, budget cycles, leadership cues, and benchmark habits can act as hidden organizational heuristics.

## 6. Test complexity fit

A heuristic that works in a stable system may fail in an adaptive system with feedback, delay, and second-order effects.

## 7. Govern stopping rules

A team should know why it stopped searching and what evidence would reopen the search.

## 8. Preserve decision memory

Rejected and deferred ideas, plus the heuristics that produced or excluded them, should become reusable learning assets.
