# Decision-Making Under Uncertainty

This article folder contains an advanced, strategist-facing companion scaffold for **"Decision-Making Under Uncertainty."**

The repository treats uncertain decision-making as a professional strategy capability: a disciplined way to classify uncertainty, compare decision frames, map assumptions, evaluate options, stress test choices across futures, preserve option value, design experiments, govern ethical responsibility, and maintain decision-learning memory.

## Why this exists

Strategic decisions are often made before outcomes are known, probabilities are stable, and system responses are visible. This scaffold helps teams avoid false precision, overconfidence, brittle optimization, premature lock-in, and outcome-only learning.

## Advanced strategist-facing capabilities

- Decision-making under uncertainty diagnostics
- Risk, uncertainty, ambiguity, complexity, and ignorance classification
- Decision-frame comparison
- Option-set quality review
- Critical assumption mapping
- Scenario stress testing
- Robustness, resilience, fragility, and exposure scoring
- Option-value and reversibility analysis
- Experimentation and staged-commitment design
- Heuristic and bias review
- Organizational decision-process review
- Ethical uncertainty review
- Decision governance and learning-memory records
- SQL schemas for options, assumptions, scenarios, experiments, ethical review, governance, and learning memory
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible uncertainty-sensitive decision analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/decision_uncertainty_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_decision_uncertainty_analytics.py
```
