# Strategic Narratives and the Logic of Direction

This article folder contains an advanced, strategist-facing companion scaffold for **"Strategic Narratives and the Logic of Direction."**

The repository treats strategic narrative as a coherence structure: the relationship among situation, diagnosis, purpose, choice, sequence, role, future state, evidence, accountability, and institutional behavior.

## Why this exists

Organizations often confuse messaging with strategic narrative. They may communicate priorities clearly while leaving the deeper logic unresolved: why this direction matters, what choices it requires, what sacrifices it implies, how action should unfold, and whether institutional behavior matches the story being told.

This scaffold helps strategists diagnose narrative coherence, direction logic, narrative-performance gaps, role alignment, stakeholder interpretation, drift, and governance.

## Advanced strategist-facing capabilities

- Strategic narrative coherence scoring
- Direction-logic and purpose-choice alignment diagnostics
- Narrative-performance gap analysis
- Choice, sacrifice, and tradeoff review
- Sequence and pathway coherence mapping
- Role-alignment and stakeholder interpretation review
- Narrative drift and fragmentation detection
- Systems-aware narrative diagnostics
- Ethical and power-aware narrative review
- Narrative governance and decision-memory templates
- SQL schemas for narrative systems and performance evidence
- Optional advanced analytics with pandas and matplotlib
- Multi-language examples for reproducible narrative analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/strategic_narrative_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_narrative_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
