# Taxonomy of Strategic Ideas

This article folder contains an advanced, strategist-facing companion scaffold for **Taxonomy of Strategic Ideas**.

The repository treats strategic idea taxonomy as a classification infrastructure for distinguishing, organizing, comparing, retrieving, evaluating, governing, and reusing ideas by type, level, maturity, domain, evidence, mechanism, relationship, lifecycle status, and ethical implication.

## Advanced strategist-facing capabilities

- Strategic idea taxonomy design
- Idea type and strategic level classification
- Maturity-state modeling
- Evidence and confidence classification
- Strategic function and mechanism mapping
- Relationship modeling across ideas
- Classification error diagnostics
- Retrieval and reuse testing
- Taxonomy governance and stewardship review
- AI-assisted classification governance
- Ethical classification and power review
- SQL schema for idea records, idea types, strategic levels, maturity states, evidence status, functions, relationships, retrieval tests, governance, and ethics
- Python, R, Julia, SQL, Rust, Go, C++, Fortran, and C examples

## Quick start

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/taxonomy_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_taxonomy_graph.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, knowledge architecture, idea-system design, taxonomy governance, institutional memory, and reproducible workflow development. They are not a substitute for executive judgment, stakeholder engagement, ethical review, legal review, information governance, privacy review, domain expertise, accountable governance, or responsible institutional change.
