# Strategic Idea Taxonomy Workshop

## Purpose

Help a team determine whether its idea classification system improves strategic judgment, retrieval, governance, learning, and accountability.

## Suggested duration

3 to 4 hours.

## Outputs

- idea inventory
- idea type map
- strategic level map
- maturity-state model
- evidence classification standard
- mechanism and function taxonomy
- relationship map
- retrieval test report
- taxonomy stewardship model
- ethics and power review
