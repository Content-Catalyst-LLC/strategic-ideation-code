# Modeling Principles for a Taxonomy of Strategic Ideas

1. Taxonomy is strategic infrastructure, not clerical labeling.
2. Classification should distinguish idea type, strategic level, maturity state, domain, function, mechanism, evidence, relationship, status, and ethical implication.
3. The first question is not whether an idea is good, but what kind of strategic object it is.
4. Different idea types require different evidence standards and review pathways.
5. Maturity classification prevents premature certainty and premature rejection.
6. Mechanism and strategic function classify ideas by logic rather than surface form.
7. Relationship mapping shows dependencies, enablers, contradictions, replacements, recombinations, tests, and warnings.
8. Retrieval tests should evaluate whether the taxonomy helps real users find useful memory at the moment of judgment.
9. AI-assisted classification requires human governance, source traceability, and ethical review.
10. Taxonomies are ethical systems because categories shape what institutions see, retrieve, value, and forget.
