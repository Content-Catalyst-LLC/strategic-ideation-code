# Bad Ideas and Strategic Failure

This article folder contains an advanced, strategist-facing companion scaffold for **Bad Ideas and Strategic Failure**.

The repository treats bad ideas as diagnosable strategic objects: weak problem frames, vague causal mechanisms, thin evidence, implementation fantasy, incentive failure, hidden ethical burden, power-protected weakness, narrative overreach, AI-amplified fluency, and missing learning design can all turn appealing concepts into strategic failure.

## Advanced strategist-facing capabilities

- Bad-idea risk diagnostics
- Problem-frame integrity review
- Causal mechanism mapping
- Claim-evidence quality assessment
- Context-fit and transfer analysis
- Implementation readiness review
- Incentive failure and gaming-risk modeling
- Ethical burden and stakeholder harm review
- Power distortion and sponsorship analysis
- Narrative honesty and overclaiming review
- AI fluency and unsupported-confidence review
- Red-team and dissent protection
- Learning design, stop-rule, and revision-trigger modeling
- Strategic failure pathway mapping
- SQL schema for ideas, assumptions, evidence, mechanisms, implementation readiness, incentives, ethical burden, power distortion, dissent, narrative honesty, stop rules, and failure learning
- Python, R, Julia, SQL, Rust, Go, C++, Fortran, and C examples

## Quick start

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/bad_idea_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_failure_pathway_graph.py
```
