# Imagination, Discipline, and Strategic Creativity

This article folder contains an advanced, strategist-facing companion scaffold for **"Imagination, Discipline, and Strategic Creativity."**

The repository treats strategic creativity as a disciplined relationship among imagination, novelty, relevance, conceptual coherence, mechanism clarity, evidence pathways, stakeholder grounding, systems fit, constraints, revision capacity, portfolio value, and decision memory.

## Why this exists

Strategic creativity is not generic brainstorming. It is the disciplined development of ideas that can reframe situations, identify new mechanisms, open better option spaces, survive scrutiny, learn from evidence, and become strategy. This scaffold helps strategists distinguish meaningful imagination from novelty theater, useful discipline from premature rejection, and mature creative judgment from either vague inspiration or rigid proceduralism.

## Advanced strategist-facing capabilities

- Strategic creativity profile scoring
- Novelty-depth and novelty-theater diagnostics
- Idea maturation modeling
- Conceptual coherence and mechanism clarity review
- Constraint audits that distinguish productive constraints from dead constraints
- Stakeholder grounding and hidden-burden review
- Systems-fit and second-order-effect review
- Evidence-pathway design for creative concepts
- Premature-convergence and overdiscipline risk flags
- Idea portfolio and developmental potential scoring
- Creative decision-memory records and reopen triggers
- SQL schemas for ideas, frames, constraints, assumptions, stakeholders, evidence, prototypes, systems review, revisions, portfolios, and decision memory
- Optional advanced analytics with pandas and matplotlib
- Multi-language examples for reproducible strategic creativity analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/strategic_creativity_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_creativity_analytics.py
```
