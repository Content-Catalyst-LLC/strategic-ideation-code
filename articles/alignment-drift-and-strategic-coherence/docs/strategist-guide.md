# Strategist Guide

This scaffold supports alignment drift and strategic coherence analysis through ten recurring questions:

1. Does strategic purpose still guide real decisions?
2. Are priorities protected from dilution?
3. Are tradeoffs being made according to strategy?
4. Do resources match stated commitments?
5. Do incentives and metrics reinforce the intended behavior?
6. Do teams interpret the strategy compatibly across levels?
7. Does governance have authority to correct drift?
8. Does feedback change decisions or merely create reports?
9. Is decision memory preserving rationale and revision triggers?
10. Are stakeholder voice, burden review, redress, and ethical commitments still intact?

Recommended workflow:

- Run `python3 python/alignment_drift_diagnostics.py`
- Review `outputs/tables/coherence_scores.csv`
- Review `outputs/tables/drift_signal_scores.csv`
- Review `outputs/tables/resource_alignment_scores.csv`
- Review `outputs/tables/incentive_metric_scores.csv`
- Review `outputs/tables/governance_strength_scores.csv`
- Review `outputs/tables/ethics_power_scores.csv`
- Use the generated markdown report for workshop discussion.
