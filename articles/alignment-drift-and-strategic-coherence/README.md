# Alignment Drift and Strategic Coherence

This article folder contains an advanced, strategist-facing companion scaffold for **Alignment Drift and Strategic Coherence**.

The repository treats alignment drift as the gradual movement of decisions, incentives, resources, metrics, routines, narratives, governance, and ethics away from strategic intent. It treats strategic coherence as the disciplined continuity of purpose, priorities, tradeoffs, resources, incentives, interpretation, governance, feedback, memory, and ethical responsibility over time.

## Advanced strategist-facing capabilities

- Alignment drift diagnostics
- Strategic coherence assessment
- Purpose-continuity review
- Priority discipline and portfolio coherence review
- Tradeoff integrity audit
- Resource alignment analysis
- Incentive and metric substitution audit
- Interpretive consistency assessment
- Narrative drift detection
- Governance strength scoring
- Feedback and adaptive coherence review
- Decision-memory assessment
- Ethical coherence and power review
- SQL schema for strategies, priorities, resources, incentives, indicators, governance reviews, stakeholder evidence, ethical commitments, drift signals, and decision memory
- Python, R, Julia, SQL, Rust, Go, C++, Fortran, and C examples

## Quick start

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/alignment_drift_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_drift_analytics.py
```
