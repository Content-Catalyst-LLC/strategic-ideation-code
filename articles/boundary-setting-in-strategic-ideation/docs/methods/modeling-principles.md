# Modeling Principles for Boundary Setting in Strategic Ideation

## 1. Treat boundaries as strategic judgments

Every problem frame includes some realities and excludes others. The boundary should be explicit enough to challenge.

## 2. Separate problem boundary from system boundary

The problem boundary supports focus. The system boundary supports understanding.

## 3. Distinguish authority, influence, and consequence

An institution may not control every consequence, but consequences outside formal authority should not disappear from strategy.

## 4. Test multiple causal frames

A strategy should compare individual, process, incentive, structural, historical, technological, and ethical explanations where relevant.

## 5. Extend time horizons

Immediate success may hide delayed harm. Evaluate immediate, short-term, medium-term, long-term, and future-stakeholder effects.

## 6. Broaden evidence responsibly

Metrics, qualitative research, stakeholder testimony, prototype evidence, scenarios, expert judgment, and ethical reasoning each show different things.

## 7. Evaluate boundary sensitivity

If an option’s value changes dramatically under stakeholder, system, long-term, or ethical boundaries, it should not be selected under a narrow internal frame alone.

## 8. Record boundary revision

Boundary change is learning when it is explicit and evidence-based. It is drift when it quietly changes the strategy.
