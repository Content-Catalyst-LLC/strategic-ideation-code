# Boundary Setting in Strategic Ideation

This article folder contains an advanced, strategist-facing companion scaffold for **"Boundary Setting in Strategic Ideation."**

The repository treats boundary setting as a professional strategic discipline for deciding what belongs inside a problem frame, what remains outside it, and how those choices shape problem definition, stakeholder inclusion, causal reasoning, time horizons, institutional responsibility, evidence legitimacy, ethical review, option evaluation, theory of change, and implementation learning.

## Why this exists

Strategic ideas can only act on what their boundaries allow them to see. Poor boundary setting produces symptom fixes, stakeholder exclusion, short-termism, causal convenience, evidence narrowing, institutional myopia, externalized burdens, boundary drift, and false precision in option evaluation. This scaffold helps strategists make boundary assumptions explicit, compare alternative frames, test boundary sensitivity, detect drift, and preserve boundary decisions in decision memory.

## Advanced strategist-facing capabilities

- Boundary quality scoring
- Problem-boundary and system-boundary comparison
- Stakeholder inclusion diagnostics
- Causal-frame adequacy review
- Temporal horizon scoring
- Institutional authority, influence, consequence, and accountability mapping
- Evidence-boundary and knowledge-legitimacy review
- Ethical boundary and burden-shift review
- Boundary-sensitive option evaluation
- Theory-of-change boundary review
- Boundary drift detection
- Revision-trigger and decision-memory design
- SQL schemas for problems, boundaries, stakeholders, causes, time horizons, institutions, evidence, ethics, options, evaluations, drift, learning loops, and decisions
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible boundary-setting analysis

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/boundary_setting_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_boundary_analytics.py
```

## Responsible use

These workflows use synthetic data and are designed for professional learning, strategic analysis, methods demonstration, institutional learning, and reproducible workflow development. They are not a substitute for stakeholder engagement, ethical review, domain expertise, accountable governance, or participatory judgment.
