# Opportunity Recognition and Evaluation

This article folder contains an advanced, strategist-facing companion scaffold for **"Opportunity Recognition and Evaluation."**

The repository treats opportunities as interpreted, tested, and governed strategic possibilities rather than objective openings waiting to be found. It supports opportunity recognition, opportunity evaluation, signal-quality assessment, capability alignment, desirability and viability review, timing analysis, risk and uncertainty scoring, portfolio comparison, ethics and power review, learning pathway design, governance documentation, and decision-memory records.

## Why this exists

Opportunity recognition is a cognitive, institutional, and strategic act. What appears as an opportunity to one actor may remain invisible to another depending on prior knowledge, framing, capabilities, timing, and strategic intent. Evaluation then requires disciplined judgment: distinguishing viable opportunities from attractive illusions, balancing upside against risk, and deciding whether an opportunity is worth staged commitment.

## Advanced strategist-facing capabilities

- Opportunity recognition diagnostics
- Signal-quality and evidence-confidence assessment
- Capability alignment scoring
- Desirability, viability, and strategic fit review
- Timing and window analysis
- False-positive and false-negative risk review
- Bias and assumption review
- Opportunity portfolio comparison
- Ethics and power review
- Learning pathway and experiment design
- Governance and decision-gate documentation
- Decision-memory records
- SQL schema for opportunities, signals, capabilities, evidence, assumptions, risk, ethics, governance, and memory
- Optional advanced analytics with pandas, numpy, and matplotlib
- Multi-language examples for reproducible opportunity evaluation

## Quick start

From this article folder:

```bash
./run_all.sh
```

Or run the main diagnostic directly:

```bash
python3 python/opportunity_recognition_diagnostics.py
```

Optional advanced analytics:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r python/requirements-advanced.txt
python3 python/advanced_opportunity_analytics.py
```
