# Strategic Ideation Code

Open computational companion repository for the Strategic Ideation knowledge series.

This repository supports articles on strategic ideation, problem framing, mental models, divergent and convergent thinking, design thinking, systems reasoning, scenario planning, decision-making under uncertainty, option evaluation, implementation alignment, adaptive strategy, and strategic measurement.

## Repository Structure

- `articles/strategic-ideation-architecture-of-ideas-complex-systems/`
  - `python/` — idea portfolio scoring, strategic fit, option architecture, and assumption mapping examples
  - `r/` — portfolio comparison, tradeoff visualization, and revision-flag workflows
  - `julia/` — strategic scoring and scenario-comparison examples
  - `sql/` — ideas, criteria, assumptions, evaluation, prototypes, and implementation schemas
  - `rust/` — command-line idea diagnostics scaffold
  - `go/` — option-evaluation utility scaffold
  - `cpp/` — efficient scoring and portfolio examples
  - `fortran/` — weighted scoring examples
  - `c/` — low-level idea-score utilities
  - `docs/` — article notes and modeling principles
  - `data/` — synthetic datasets
  - `outputs/` — generated outputs
  - `notebooks/` — notebook placeholders

## Modeling Principles

1. Do not confuse novelty with strategic value.
2. Make assumptions visible.
3. Distinguish idea generation from idea evaluation.
4. Treat scoring as a support for judgment, not a replacement.
5. Evaluate ideas across feasibility, relevance, fit, risk, learning, and implementation readiness.
6. Preserve ethical and stakeholder questions in strategic framing.
7. Connect ideas to implementation pathways and learning loops.
8. Use computation to make reasoning inspectable and revisable.
